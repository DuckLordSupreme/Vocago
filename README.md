# Vocago

Vocago is a desktop vocabulary-learning application built with
Java 21 and Swing.

## Running Vocago

Requires Java 21.

```bash
java -jar OOP25-Vocago-all.jar
```

## Features

- Multiple user profiles
- Custom vocabulary collections
- Vocabulary practice
- Progress statistics
- Persistent user data

## Technology

Java 21 · Swing · Gradle · JUnit 5
